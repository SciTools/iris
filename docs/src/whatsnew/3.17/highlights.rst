   The highlights for this major/minor release of Iris include:

   * Added native Zarr support. Iris can now read Zarr versions 2 and 3, and write version 3.
   * Iris's AGENTS.md files have been rewritten from a month's experience of AI-assisted development: a new source-code style guide, an architecture map, a shared writing guide, and testing rules that record what the suite does not cover.

   * We also want to thank :user:`syahra712`, :user:`mo-AndrewCreswick`, :user:`rcomer` and :user:`01luyicheng` for their contributions that have gone into this release.

   And finally, get in touch with us on :issue:`GitHub<new/choose>` if you have
   any issues or feature requests for improving Iris. Enjoy!
